Photographs were consulted as visual references; their bitmap pixels are not embedded in the game. The five user-provided boards are included unchanged as repository reference files. Their visual content is not proof of a site's exact current appearance. No Google imagery, satellite tiles or photogrammetric assets are redistributed.

## Verification limits

Automated checks cover map validity, home plot rejection, home traversal with Rapier, flight/landing, vehicle spawn clearance, roundabout centroids, existing navigation/save behavior and network payload validation. Browser checks cover the local rendered game and room creation/join flow. Browser viewport/touch-layout checks are not measurements on physical iPhones, iPads or Android hardware. Low-latency snapshots do not guarantee zero network lag. Shared authoritative physics, shared property ownership, synchronized NPCs and cloud accounts are not implemented.
